# micr0Flow_cc_moudle

microFlow 恒流控制模块。

- 支持手动、自动恒流及流量缓变往返循环（固件 1.1.0）。
- [流量缓变模式说明](流量缓变模式说明.md)：小时级渐变、三点有效停留、阶段总时限、阀门边界故障及新增寄存器。
- [热式流量近似换算](热式流量近似换算.md)：固件 1.1.1 新增示例曲线模板，可用零点和任意已知参考流量点的电压校准，默认保留原线性换算。
- 固件 1.1.2：缓变配置统一到 48031 起，实时状态统一到 48083 起；保留已有标定、缓变参数和 Flash 布局。
- 固件 1.1.3：缓变配置和状态直接加入 `RSVD_PARAM_T`，扩展为 104 个寄存器（208 字节）；同步扩展 Flash 保存、出厂参数及旧数据迁移。
- 固件 1.1.4：恒流 PID 下限和缓变默认下限降为 20%，升级时迁移原默认 35% 的缓变下限。
- 固件 1.1.5：上电保持已保存的模式 2，从低点重新开始缓变，阶段进度和循环次数清零。
- 固件 1.1.6：无效流量采样不再阻挡手动接管；运行和上电共用标定校验，保留合法的 0～3.3 V 标定电压。

- [简易通讯说明](通讯说明.md)：默认地址 20，Modbus RTU，9600 / 8E1。

## 本地验证

- `python tests/check_host.py`：模拟时钟、串口寄存器和 Flash，检查实际 C 源码的流量控制、缓变、换算、参数迁移及 Modbus 访问。
- `python tests/check_firmware.py`：在临时目录编译链接 APP，需要 PATH 中有 ARM GCC；不覆盖 IDE 构建产物。
- 2026-11-04：上述检查通过，APP 的 57 个源文件编译链接成功。现有 `modbus_app.c` 有一处静态函数声明未定义的警告；这些检查不替代实物闭环及显示联调。
